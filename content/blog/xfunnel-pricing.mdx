## What does the public documentation not disclose?

That leaves practical questions unanswered until sales responds: which engines and regional variants are included; whether a “check” means one prompt-engine observation or a larger unit; how long snapshots are retained; whether brands and competitors share an allowance; and whether seats, exports, API calls, onboarding, implementation, and support cost extra.

## How should you request a comparable Xfunnel quote?

Send Xfunnel a short written scope and ask the representative to return assumptions beside every number. The objective is not merely to receive a total; it is to make the total reproducible when your monitoring program changes.

Use the official [Xfunnel contact route](https://www.xfunnel.ai/contact), then ask the reply to identify:

1. Package name, contract term, included volume, and measurement unit.
2. Engines, markets, languages, brands, competitors, workspaces, seats, exports, API access, integrations, and retention.
3. Onboarding, training, support, implementation fees, renewal pricing, cancellation notice, termination assistance, data export, and overage approval.

Ask for a quote that separates recurring platform fees from one-time services. If Xfunnel offers a pilot, request its success criteria, data ownership, end date, conversion terms, and any fees payable when it ends.

## What scope should you put in the worksheet?

Start with the workload, not a plan label. The following reproducible example uses a simple unit: one prompt checked against one engine during one scheduled run.

### Scope worksheet: 200 prompts across six engines

| Input | Example value | Calculation or question for Xfunnel |
| --- | ---: | --- |
| Prompts | 200 | Buyer, category, comparison, and branded prompts |
| Engines | 6 | Name each engine and regional variant |
| Runs per month | 4 | Weekly schedule; confirm timezone and run date |
| Checks per month | 4,800 | 200 × 6 × 4 |
| Brands | 2 | Confirm whether each brand is a separate allowance |
| Markets | 3 | Confirm language, country, and localization coverage |
| Seats | 5 | Confirm viewer, editor, and admin roles |
| Retention | 12 months | Confirm raw observations and report retention |
| Exports/API | Required | State CSV, PDF, webhooks, and API needs |

Put this sentence in the request: “Please quote 200 prompts × 6 engines × 4 monthly runs = 4,800 checks per month, for two brands and three markets, with five seats, 12-month retention, exports/API access, onboarding, support, renewal, cancellation, and overage terms itemized.”

Then ask whether Xfunnel defines a check differently. If it counts a prompt batch, a generated report, or a multi-query workflow as a unit, have the representative restate the formula using Xfunnel’s own definition. Keep the original worksheet beside the quote so you can compare future invoices against the same scope.

## What should you verify before signing?

Treat the quote as incomplete until its usage definitions and exit terms are explicit. Confirm that the proposal names every engine, geography, language, brand, competitor set, and run schedule you expect to use. Verify whether deleted prompts, failed runs, duplicate observations, and retries consume allowance.

Read the data terms with the same care as the price. Ask who owns raw observations and derived reports, how long data remains available after cancellation, and whether you can export a machine-readable history. Confirm that API limits, service credits, and support channels are in the order form.

Finally, ask what happens at renewal. Request the renewal formula, notice period, and process for reducing scope, and keep the signed proposal with the worksheet.

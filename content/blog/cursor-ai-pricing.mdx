Cursor pricing is easiest to understand as a capacity decision, not a feature-shopping exercise. Hobby is useful for trying the editor; Pro is the sane individual default at $20 per month; Pro+ and Ultra are for people whose normal workload repeatedly exhausts lower-tier limits; Teams adds shared controls at $40 per user per month.

Paid plans describe extended Agent limits, frontier models, and usage-based behavior—not unlimited identical requests. This guide uses pricing checked September 13, 2026; verify the [official Cursor pricing page](https://cursor.com/pricing) before purchasing.

## What does Cursor cost?

Cursor ranges from free Hobby access to $200 monthly for Ultra. Pro is $20 monthly or $16 annual equivalent; Pro+ is $60; Teams Standard is $40 per user monthly.

| Plan | Price | Best fit | Main implication |
|---|---:|---|---|
| Hobby | Free | Trying Cursor or occasional coding | Limited usage, no recurring cost |
| Pro | $20/month; $16 annual equivalent | Most individual developers | Strong regular-use default |
| Pro+ | $60/month | Heavy Agent users | More capacity after proven interruptions |
| Ultra | $200/month | Very high-volume individual work | Specialist-level commitment |
| Teams Standard | $40/user/month | Teams needing shared administration | Per-seat cost plus controls |

The [account pricing documentation](https://cursor.com/docs/account/pricing) explains individual plans and usage behavior. [Teams pricing documentation](https://cursor.com/docs/account/teams/pricing) covers team details.

My position is simple: start with Pro unless evidence shows Pro interrupting completed work. Do not buy Ultra because a larger number feels safer. Buy capacity after logs show limits, context-heavy tasks, or repeated model use create measurable friction.

## How does usage-based pricing work?

Cursor plans are access to a practical AI-work budget, not a fixed count of identical prompts. A short autocomplete and a long Agent task reading a large repository have different computational and workflow costs.

“How many requests do I get?” is therefore the wrong first question. Effective usage changes with Agent sessions, model choice, repository context, retries, parallel branches, and broad versus narrow refactors.

Two developers can pay for the same plan and experience different value. One may use focused implementation and finish comfortably. Another may run continuous autonomous work across a monorepo and reach practical limits quickly.

The right metric is completed work per dollar, with interruptions and rework included.

## Which plan fits an individual?

Hobby fits evaluation; Pro fits most regular individual work; Pro+ and Ultra require evidence of heavier demand.

### When is Hobby enough?

Hobby answers “Do I like Cursor?” It is right for learning the workflow, occasional coding, and testing the interface, but it is not a dependable baseline for daily Agent work.

### Why is Pro the default?

Pro balances meaningful capacity with manageable cost. It fits regular coding across a few active repositories when most tasks finish without recurring limit interruptions.

The strongest reason to choose Pro is not merely that it is inexpensive. It is capable enough to reveal whether Cursor belongs in the workflow without making a specialist-level commitment.

### When is Pro+ worth it?

Pro+ is justified when Pro repeatedly becomes a constraint. Look for unfinished tasks, delayed reviews, large-context debugging, or work moved elsewhere because capacity was exhausted.

If those events are rare, Pro+ may be paying for anxiety. If they happen weekly and interrupted work has real value, the extra $40 may be rational.

### Who should consider Ultra?

Ultra fits sustained, high-volume Agent use across repositories with little tolerance for capacity interruptions. At $200 monthly, it must create measurable value after review and correction.

It is not the “best” plan by default. If it does not clearly generate more than $200 of monthly value, the upgrade is difficult to defend.

## What does Cursor Teams cost?

Teams Standard is $40 per user monthly. Five seats therefore cost $200 monthly before taxes or separately applicable usage terms.

The team case includes administration, onboarding, offboarding, consistency, and governance—not just model access. Track number of seats, active usage, review requirements, shared-management time, and the cost of inconsistent tooling.

Do not assume everyone needs a seat immediately. Start with people doing meaningful daily AI-assisted development and expand after the workflow proves value.

## Which hidden costs matter?

The subscription is only part of Cursor’s cost; review and correction often dominate. Generated code that needs extensive repair is not cheap.

Count time spent repeating prompts, rebuilding context, reviewing broad changes, fixing missed tests or migrations, switching models, and restating repository conventions.

Use this worksheet:

```text
Monthly Cursor cost
+ review and correction time
+ failed-task time
+ other tool subscriptions
--------------------------------
Cost per merged change
```

Compare that figure with the previous workflow. If Cursor produces more merged changes with equal or lower review burden, it is working. If it produces more code but not more merged outcomes, a higher tier may amplify waste.

## How should you run a seven-day pilot?

Run a seven-day pilot before changing plans. Record each meaningful Agent task, model category, whether the change merged, retry burden, and any limit or context interruption.

At week-end, answer:

1. How many tasks reached production-quality completion?
2. How many needed substantial manual rewrite?
3. How often did capacity interrupt work underway?
4. What would one additional successful merged change be worth?

If Pro completes important work and interruptions are exceptional, stay on Pro. If interruptions are frequent and expensive, test Pro+ for one billing period. Move toward Ultra only when workload is consistently high and economically measurable.

## When should you choose an alternative?

Choose by the workflow, not a theoretical feature list. Terminal-first developers can compare [Claude Code pricing](/blog/claude-code-pricing); teams wanting another ecosystem can review [Microsoft Copilot alternatives](/blog/microsoft-copilot-alternatives); broader comparisons belong in [Cursor AI alternatives](/blog/cursor-ai-alternatives).

The best alternative produces completed, reviewed changes with least friction. A cheaper subscription can cost more through context loss and setup; a higher subscription can be wasteful when specification quality—not capacity—is the bottleneck.

## What is the verdict?

Cursor Pro is the right default for most individual developers. Choose Pro+ only after usage records show recurring interruptions, treat Ultra as a specialist investment, and evaluate Teams through administration plus active-seat value.

Start small, measure merged work, and upgrade only when evidence says capacity is limiting output. If buyer-answer visibility is part of the broader product workflow, compare the separate [AEOeye pricing](/pricing) decision on its own terms.

## Frequently Asked Questions

### Is Cursor free?

Yes. Hobby is free and suitable for trying the editor or occasional use. Do not assume it provides capacity for sustained professional Agent work.

### How much does Cursor Pro cost?

Cursor Pro costs $20 per month or $16 per month on the annual equivalent. It is the recommended starting plan for most regular individuals.

### Is Cursor Pro+ worth it?

Pro+ costs $60 per month and is worth considering when Pro repeatedly interrupts valuable work. Measure unfinished tasks, retries, and review time first.

### How much does Cursor Teams cost?

Teams Standard costs $40 per user per month. Multiply by active seats, then evaluate administrative and collaboration value alongside usage.
